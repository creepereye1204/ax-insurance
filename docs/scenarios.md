# 업무 시나리오

데모 데이터의 **시나리오 고객**으로 가입설계부터 청구까지 주요 업무 규칙을 확인한다. 모든 고객·상품·심사 기준은 가상이다.
자동 실행: `python3 scripts/scenarios.py` (기간계 API 를 호출해 기대 결과를 검증, 15개 시나리오)

| 고객 | 특징 | 숨은 이력 / 속성 |

| 김정상 | 이력 없음, 위험중립형 | - |

| 한골절 | 골절 수술 후 치료 중 | 외부기관: 6개월 전 S82.2 수술, 미완치 |
| 정전문 | 전문금융소비자 | 금융투자업 종사자 |

## 시나리오와 기대 결과

| # | 시나리오 | 확인하는 규칙 | 기대 결과 |
|---|---|---|---|
| S01 | 김정상 — 건강보험 설계 → 고지 없음 → 서명 → 제출 → 청약철회 | 자동 승인, 청약철회 15일 | 계약 성립 → `WITHDRAWN` |
| S02 | 이위염 — 동의 → 선심사 | 선심사(청구이력·외부기관), R-GI-01 | 위·십이지장 부담보 **예상** |
| S03 | 이위염 — 위염을 고지하지 않고 실손 가입 → 위염(K29.7) 청구 | 고지의무 위반 의심 점검 | 청구 점검에 "고지의무 위반 의심" + 외부기관 출처 |
| S04 | 박당뇨 — Q4 에 E11.9 투약 고지 | R-DM-01 본사 이관, AI 참고의견, 담보별 결정 | 본사 이관 → 심사자가 실손만 거절 → 나머지 담보로 계약 성립 |
| S05 | 최고령 — 일반 종신 설계 / 간편심사형 종신 청약 | 가입나이, 고령자 보호 확인 | 일반형은 나이 초과 오류, 간편심사형은 **고령자 보호 확인 항목** 없이 제출 불가 |
| S06 | 한골절 — Q3 에 S82.2 수술 고지 → 골절 청구 | R-FX-01 부담보, 청구 시 부담보 점검 | 골절 부위 부담보로 계약 → 청구에 "부담보 해당" |
| S07 | 오안정 — 변액연금 주식형 70% | 적합성 원칙 | "부적합" → 고객 확인 없이 설계서 발행 불가, 확인 후 발행 |
| S08 | 정전문 — 변액연금 주식형 70% | 전문금융소비자 | "적합성 원칙 적용 제외" |
| S09 | 강공격 — 변액유니버설 주식형 | 적합, 변액 원금손실 확인 | 적합 → 청약 시 원금손실·예금자보호 미적용 확인 필수 |
| S10 | 윤위험 — 운전자보험 | R-JOB-01 직업 할증 | 상해 담보 50% 할증, 계약 보험료 > 설계 보험료 |
| S11 | 서임신 — Q5 임신 "예" | R-PRG-01 | 수술·입원 담보 임신·출산 부담보 |
| S12 | 문다청구 — 실손 청약 | R-CLM-01 잦은 청구 | 본사 이관 |
| S13 | 유어린 — 종신 / 어린이보험 | 가입나이 | 종신은 나이 미달, 어린이보험은 계약 성립 |
| S14 | 검증 — 서명자 불일치, 고지 상세 누락, 설계서 재사용 | 입력 검증 | 각각 오류 메시지 |
| S15 | 전산심사 버튼(사전 실행) — 김정상 / 박당뇨(당뇨 고지) | 제출 전 심사 결과 확인, 저장 안 함 | 자동 승인 예상 / 본사 이관 예상, 설계서는 그대로 |

## 업무 흐름

```
고객 → 가입설계(상품·납입기간·담보·가입금액 / 월납입액·연금개시·펀드) → 보험료·예시표·적합성
     → 설계서 발행(30일 유효, 스냅샷 고정)
     → [선심사: 동의 → 청구이력·외부기관 조회 → 예상 결과]
     → 청약: 알릴의무 고지 → 청약서 확인(문서 해시) → 전자서명(필수 확인 항목) → 제출
     → 전산심사 → 자동 승인 / 본사 이관(AI 의견 → 심사자 결정) / 연기 / 거절
     → 계약 성립(담보별 부담보·할증) → 15일 청약철회
     → 청구: 부담보·고지위반 점검 → AI 약관 검토 → 심사자 결정
```

## 대량 데이터 (성능 테스트용)

| 데이터 | 건수 |
|---|---|
| 상품 / 담보 | 201 / 약 500 |
| 요율표 | 약 11.5만 행 |
| 고객 | 약 3만 명 (전문금융소비자 3%, 투자성향 진단 40%) |
| 기존 계약 / 계약담보 | 6만 / 약 11.6만 |
| 보험금 청구 | 50만 건 |
| 외부기관 의료이력 | 5만 건 |

`BulkDataSeeder` 가 PostgreSQL `generate_series` 로 약 35초에 생성한다(같은 시드 → 같은 데이터).
성능 개선 전 상태를 측정하기 위해 **인덱스는 일부러 추가하지 않았다** (설계 문서 12절).
